# Rights and compatibility notice

This repository is an unofficial compatibility project for FishOnMC.

- FishOnMC names, trademarks, game content, server software, official artwork, and underlying character
  or item designs are not claimed by this project.
- The repository contains replacement artwork created for interoperability with FishOnMC's existing item
  identifiers. It is not an official FishOnMC distribution.
- No extracted official fish texture was intentionally included. A local pre-publication SHA-256 audit
  found zero exact matches against 2,431 cached official fish PNG hashes.
- The two model JSON files are minimal Minecraft generated-item declarations containing only a standard
  `item/generated` parent and a replacement texture path.
- The artwork was produced through a human-directed, AI-assisted workflow and subsequently selected,
  processed, corrected, and tested in Minecraft.

If you represent a relevant rights holder and believe a file should be changed or removed, open an issue
at <https://github.com/finalpantasy/fishonmc-rustic-fantasy-128/issues>.
